# BCG Churn Analysis & Business Strategy 📊

## Project Type
BCG Virtual Experience Program (Forage)

## Duration
March 2025 – July 2025

## Overview
This project is based on a real-world consulting simulation focused on analyzing customer churn and developing data-driven business strategies.

## Key Objectives
- Analyze customer behavior and churn patterns
- Perform exploratory data analysis (EDA)
- Engineer features for predictive modeling
- Build insights to reduce churn and improve retention

## Work Done

### 1. Financial Analysis
- Net Present Value (NPV) and IRR calculation
- Investment decision modeling

### 2. Data Analysis
- Customer usage and pricing analysis
- Identification of churn patterns
- Statistical insights and trends

### 3. Machine Learning
- Feature engineering
- Predictive modeling for churn
- Model evaluation (ROC AUC ~0.75)

### 4. Business Strategy
- Identified key churn drivers:
  - Price sensitivity
  - Usage patterns
  - Contract terms
- Proposed retention strategy:
  - Targeted discounts
  - Data-driven interventions

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## Business Impact
- Predicted churn with ~75% accuracy
- Suggested strategies to improve retention
- Estimated revenue impact through targeted actions

## Conclusion
This project demonstrates the ability to combine data analysis, machine learning, and business thinking to solve real-world problems.
